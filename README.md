

# AIG Cybersecurity Job Simulation – Forage

> Virtual cybersecurity experience program completed through Forage in partnership with American International Group (AIG).  
> This simulation focused on real-world cybersecurity operations, threat analysis, phishing investigations, and incident response workflows commonly used in enterprise environments.

---

## 📌 Program Overview

This repository contains notes, reports, screenshots, and deliverables completed during the AIG Cybersecurity Virtual Experience Program. The simulation provided hands-on exposure to cybersecurity analyst responsibilities and Security Operations Center (SOC) workflows through practical business scenarios.
